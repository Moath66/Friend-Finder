# Task 1- Friend-Finder

A simple JavaScript project that allows users to search for friends by name.

## Features

- Search for friends by name.
- Case-insensitive search.
- Find partial matches.
- Handle empty search input.
- Handle invalid input.
- Support asynchronous data loading.

## Technologies Used

- JavaScript (ES6+)
- Node.js
- Jasmine

## Installation

Clone the repository:

```bash
git clone https://github.com/Moath66/Friend-Finder.git
```

Go to the project folder:

```bash
cd Friend-Finder
```

Install the dependencies:

```bash
npm install
```

## Running Tests

To run the Jasmine tests, use:

```bash
npm test
```

## About

This project was built to practice JavaScript fundamentals, asynchronous functions, array methods, and writing tests with Jasmine.
